# 06-01: Introduction to pointers

The code examples below use the following code:

```c
int intA = 10;
int intB = 2;
float floatA = 10.0;
float floatB = 2.0;
char character = 'X';
```

## Terms and terminology

### Pointer data type

The `*` in a data type denotes a pointer to another data type.
The number of `*` symbols corresponds to the level of indirection.

```c
int *numberPtr;
float *floatPtr;
char *charPtr; // Note: this is not a string.
```

### Address-of operator `&`

The `&` operator produces the address of its operand.

```c
numberPtr = &intA;
floatPtr = &floatA;
charPtr = &character;
```

### Dereference operator `*`

The `*` operator denotes either multiplication or dereferencing.
Its meaning is determined by the context.

```c
// Read a value from an address.
intA = *numberPtr;
floatA = *floatPtr;
character = *charPtr;
```

```c
// Write a value to an address.
*numberPtr = 42;
*floatPtr = 42.42;
*charPtr = 'Y';
```

### Printing a pointer value

A pointer's value is an address.
Use the `%p` format in `printf` to print an address:

```c
printf("Address: %p == %p", numberPtr, &intA);
printf("Referenced value: %d == %d", *numberPtr, intA);
```

### Passing parameters by reference

Functions requiring references specify the corresponding data types in their declarations.

```c
void swapInts(int *a, int *b);
```

Call them using the address-of operator as follows:

```c
swapInts(&intA, &intB);
```
